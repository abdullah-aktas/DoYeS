# Teknik Müdür Yardımcısı kılavuzu

**Yasal görev:** Gerçekleştirme görevlisi. İşi ve puantajı kontrol edip **Uygundur** imzasını verir.

Platform: [PLATFORM.md](PLATFORM.md) · Ortak: [ORTAK.md](ORTAK.md)

## Tipik akış

1. Ana ekranda size düşen onayları açın.
2. Sipariş / parça başı / fazla çalışma kaydını kalem kalem kontrol edin (miktar, kişi, tutar, bölüm).
3. Uygunsa **Uygundur**; değilse gerekçeyle **İade et**.
4. Müdür olur verdikten sonra süreç saymana (ödeme / fatura) veya ilgili birime geçer.

## Ne yapmazsınız

- Fatura, kasa, stok, hazine kaydı açmazsınız (sayman).
- Kullanıcı davet etmezsiniz (müdür / sistem yöneticisi).
- Merkez parametre doğrulamazsınız (sayman).

## İpuçları

- İade edilen kayıt düzenlenip yeniden onaya gelir; işlem kaydında iz kalır.
- Mobilde onay listesini Ana ekrandan takip etmek en hızlı yoldur.
